# v1.5.0 — Large Order Book handoff

## Outcome

The Large Order Book feature is complete on `codex/large-order-book` (feature
commit `d3ad242`). It shows live BTC/ETH liquidity walls from Binance and OKX
in the right-side DOM panel and directly on the chart. Historical inactive
walls are optional; live rendering does not depend on history availability.

## Data flow

`cryptofeed` L2 snapshot/delta callbacks feed `LargeOrderBookService`, which
tracks price-level lifecycles in memory and flushes captured walls to
PostgreSQL. Live events use the existing EventBus and `/ws` gateway.

Each WS connection receives one full, sequenced snapshot per source/symbol.
Subsequent 500 ms batches contain only changed levels and removed IDs. The
frontend applies each delta in one Zustand update. A sequence gap closes the
socket so the existing reconnect path supplies a fresh snapshot. Empty delta
heartbeats advance the sequence without causing React renders, ensuring a
dropped final removal is eventually detected.

## Operational boundaries

- Capture floor: `$500,000`; UI thresholds range from all captured levels to
  `$10,000,000`.
- History retention: 30 days. The history endpoint defaults to 1,000 rows;
  the panel and chart request 250 and 500 respectively.
- Sources remain Binance and OKX only; symbols remain BTC and ETH only.
- No order execution, signal generation, or OKX conditional-order behavior is
  attached to this indicator.
- Monitor short-lived wall churn and database growth. Do not add another
  storage/streaming layer unless measurements justify it.
